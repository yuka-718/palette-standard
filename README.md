# Palette Standard

**「色のバリアフリーを、すべての人へ」**

Palette Standard は、色覚多様性を持つ人とクリエイター双方の「色の障壁」を、ブラウザだけで検出から解決まで支援するアクセシビリティ・プラットフォームです。

## 3つのモジュール

- **Color Bridge** — 画像のP型・D型・T型シミュレーションと、明度・模様による自動補正
- **Edu Vision** — 教材や黒板で同化した赤系文字の抽出、白ふち・白文字・下線による補正
- **Color Talk** — 2色の色名、色相差、コントラスト比に基づく自然言語の配色アドバイス

画像処理は HTML5 Canvas API で端末内に完結し、画像をサーバーへ送信しません。

## ローカル起動

```bash
npm install
npm run dev
```

## GitHub Pages

`main` ブランチへの push で GitHub Actions が静的サイトをビルドし、GitHub Pages へ公開します。

## アクセシビリティ方針

- CUD推奨色をベースに、通常文字は原則 WCAG 2.2 AA（4.5:1）以上
- 状態やカテゴリを色だけで示さず、文字・アイコン・模様・太枠を併用
- キーボードフォーカス、スキップリンク、動きを減らす設定に対応
- シミュレーションは「見分けにくさの推定」であり、実際の見え方を断定しない
