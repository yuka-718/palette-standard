# BridgePalette

**「色のバリアフリーを、すべての人へ」**

BridgePalette は、色覚多様性を持つ人とクリエイター双方の「色の障壁」を、ブラウザだけで検出から解決まで支援するアクセシビリティ・プラットフォームです。

## 2つのコア機能

- **Color Bridge** — C型で元画像を比較し、P型・D型・T型・A型の見え方を参考表示。P・D・T型は画像内の混同色を解析して色・模様で補正し、A型は模様で補助。教材・黒板向けプリセットでは赤系の強調箇所へ白い縁を追加
- **Color Lens** — カメラ中央の色を端末内で読み取り、日本語の色名・HEX・RGBを表示

画像処理は HTML5 Canvas API で端末内に完結し、画像をサーバーへ送信しません。

## 色覚タイプの表記

CUDOの呼称を参考に、C型（一般色覚・比較用）、P型、D型、T型、A型を表示します。C型は元画像との比較専用で補正は行いません。P・D・T・A型が色覚特性の主な分類で、A型は単純な白黒表示と同一ではないため参考表示としています。同じ型でも程度や見え方には個人差があります。

## アクセシビリティ方針

- CUD推奨色をベースに、通常文字は原則 WCAG 2.2 AA（4.5:1）以上
- 状態やカテゴリを色だけで示さず、文字・アイコン・模様・太枠を併用
- キーボードフォーカス、スキップリンク、動きを減らす設定に対応
- シミュレーションは「見分けにくさの推定」であり、実際の見え方を断定しない

## 色補正の根拠

- Machado et al.（2009）のP・D・T型シミュレーションを線形sRGBで実行
- 画像内の代表色間をCIEDE2000で比較し、対象タイプで色差が失われる組を検出
- CUD推奨配色セット ver.4を候補に、補正後の推定色差を再評価
- CIELAB L*を維持して輝度変化を抑え、補正前後の指標を画面に表示

詳しい手順と限界は [色補正エンジンの説明](docs/color-correction-method.md) に記載しています。
